# Oways Tech — أويس تك

موقع عربي RTL للخدمات الرقمية. مشروع مستقل عن Radius Lord.

## التشغيل محليًا

يتطلب Python 3 لتشغيل المعاينة:

```sh
python -m http.server 8080 --directory dist
```

افتح http://localhost:8080 في المتصفح.

## تعديل الموقع

- `dist/config.js`: الخدمات، المميزات، الأسعار، العملة، ورقم واتساب.
- `dist/index.html`: محتوى الأقسام والروابط.
- `dist/style.css`: التصميم والألوان والتجاوب.
- `dist/app.js`: السلة ورسائل التواصل وطلبات التجديد.

أدخل رقم واتساب بصيغته الدولية بالأرقام فقط دون +. قيمة السعر `null` تعرض «حسب الخطة»؛ استبدلها برقم لعرض السعر.

السلة محفوظة محليًا في متصفح الزائر. لا توجد بوابة دفع أو تجديد تلقائي. يتم تأكيد الأسعار والمدة وتفاصيل التنفيذ قبل الطلب. عند غياب رقم واتساب تظهر رسالة قابلة للنسخ.

## النشر

ملفات `dist` جاهزة لأي استضافة ثابتة. النسخة الحالية منشورة عبر Sites. رفع التعديلات إلى GitHub لا يحدّث نسخة Sites تلقائيًا؛ يجب نشر التعديلات أيضًا. لم تُفعّل GitHub Pages أو أي خدمة نشر إضافية.
