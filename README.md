# Oways Tech — أويس تك

مشروع مستقل باللغة العربية وRTL، بخادم Node.js 24 وMySQL. الخادم يعرض ملفات الواجهة من dist ويشغّل API.

## التشغيل المحلي

أنشئ .env من .env.example وأدخل بيانات MySQL، ثم:

```bash
npm install
npm run db:migrate
npm start
```

الموقع http://localhost:3002. على قاعدة جديدة فقط يمكن استخدام npm run db:init بدل الترحيل. لا تستخدم db:init على قاعدة موجودة.

## الحسابات والجلسات

العميل ينشئ حسابًا بالاسم ورقم الهاتف وكلمة مرور من 6–128 محرفًا وتأكيدها. الدخول برقم الهاتف وكلمة المرور، ولا يوجد OTP أو حاجة إلى SMS أو WhatsApp API. الهاتف غير موثّق ولا تُمنح له phone_verified_at عند التسجيل. كلمات المرور محفوظة باستخدام scrypt وsalt عشوائي.

الأدمن يدخل من /admin-login باسم مستخدم وكلمة مرور. أنشئه عبر npm run admin:setup. الجلسة العادية لكليهما يوم واحد (24 ساعة)، وتذكّرني يحفظها لمدة 30 يومًا. بدون تذكّرني ينتهي ملف تعريف الجلسة عند إغلاق المتصفح، رغم بقاء صلاحية الجلسة على الخادم يومًا. تسجيل الخروج يلغي الجلسة فورًا. لا يوجد مؤقت خروج عند 30 دقيقة.

## تحديث القاعدة الموجودة

نفّذ database/002_customer_passwords.sql داخل القاعدة المحددة في phpMyAdmin، أو npm run db:migrate محليًا. ينشئ customer_credentials دون حذف البيانات أو تغيير كلمات مرور الأدمن. لا حاجة لإعادة استيراد القاعدة كاملة.

الحسابات القديمة تحتاج تعيين كلمة مرور من مسؤول موثوق بعد التأكد يدويًا من هوية العميل:

```bash
npm run customer:password -- +963XXXXXXXXX
```

الأداة تطلب كلمة المرور وتأكيدها دون طباعتها، تلغي جلسات العميل السابقة، وتسجّل العملية في audit_logs. لا يوجد تعيين كلمة مرور تلقائي للحسابات القديمة أو استعادة ذاتية غير موثّقة.

## النشر على Hostinger

اختَر Other، الفرع main، Node 24، الجذر ./، دون أمر بناء، ودليل إخراج .، وملف الدخول server/index.js. عند استعمال npm start لا يلزم وجود ملف .env؛ المتغيرات المحقونة من الاستضافة تكفي. حافظ على server وdist ضمن نفس حزمة النشر.

متغيرات الإنتاج: NODE_ENV=production وHOST=0.0.0.0 وAPP_ORIGIN=https://your-domain.com وDB_HOST وDB_PORT وDB_NAME وDB_USER وDB_PASSWORD. المنفذ يُؤخذ من PORT الذي توفره الاستضافة. احذف متغيرات OTP القديمة؛ لم تعد مطلوبة. لا تضع الأسرار في GitHub. استورد القاعدة الحالية في قاعدة Hostinger الجديدة ثم نفّذ ترحيل 002 إذا لم يكن الجدول موجودًا.

## الميزات والحدود

الخدمات والتصنيفات والباقات والمتطلبات والصور ومعلومات التواصل، حساب العميل وطلباته ورسالة الدعم المرتبطة بالخدمة، مراجعة الأدمن وتأكيد الدفع يدويًا مع المسؤول والتوقيت، ومنع بدء التنفيذ قبل الدفع. إكمال التفعيل وإدارة عروض الأسعار وتعديل الخدمات الحالية ليست مكتملة بعد.

مراجعة التجاوب تشمل الرئيسية والحساب ولوحة الإدارة والنوافذ المنبثقة؛ فحص المتصفح الفعلي يُذكر منفصلًا عن فحص الكود. npm test يشغّل اختبارات الحماية وكلمات المرور والجلسات والتحقق من البيانات والصور.
